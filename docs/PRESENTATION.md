# Project positioning and film narrative

**Positioning:** WireSight is an open visual-observation interface and original-point executor for conversation-VLM-driven 3D annotation, demonstrated first on wires.

**Lead with the result:** a real five-wire 3D annotation on a scene with 59.6M original records. Let visitors rotate the cloud, compare display coloring, then inspect how the observer reached its choices.

**Three concrete strengths:**

1. Connect existing visual understanding to 3D tasks through height-aware projected views. The current example did not train a dedicated 3D segmentation network.
2. Let task questions determine extra views, local inspection and fragment associations. Recorded choices and abstentions make the observer's role visible.
3. Turn image decisions into traceable original-record labels through explicit selection and execution, with replay and export checks.

**Film:** question and 3D result → top-down visual evidence and exact recorded paths → complementary views → original-point mapping → real abstention → frozen annotation → full-scope point metrics → interface value → open-source entry points. English synthetic narration explains the images; the complete action trace remains available for deeper inspection.

**Scientific context:** using 2D vision-language capabilities for 3D tasks is an active research direction. [SeeGround (CVPR 2025)](https://seeground.github.io/) adapts rendered views and spatial descriptions for 3D visual grounding. [Reason3D (3DV 2025)](https://reason3d.github.io/) studies point-cloud/text reasoning with segmentation outputs. These projects support the relevance of the direction; their architectures, tasks and metrics differ from this wire prototype and are not evidence for our performance or priority.

**Evidence boundaries:** the current metric is an inspected development-scene result. It does not establish VLM superiority, unattended success, held-out generalization or optimal token compression. Avoid claims such as "first", "state of the art", "fully automatic" or "universally transferable" without corresponding independent evidence.

**Integrity:** use actual images and recorded selections; label editorial narration as narration, preserve local-branch scope, and distinguish display coloring from the raw images supplied to the observer. Keep evaluation scope visible beside quality metrics. Do not invent confidence scores, point growth or fresh model calls for visual impact.
