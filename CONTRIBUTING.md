# Contributing

Start with the small recorded ROI and failure-oriented protocol tests. Keep original record IDs, explicit observer provenance and unconfirmed status intact. Candidate generation is not confirmation; contradictory or stale evidence must not be silently accepted.

For fresh quality claims, declare scene and target scope before observation, freeze outputs before truth access, include unknown targets in recall, and report per-scene failures. Saved action replay only checks execution. Do not attribute historical conversation-VLM results to a different local model.

Keep datasets, credentials and weights out of commits. Derived visual assets require their own dataset attribution. Run the checks in README.md and add focused tests for material executor changes.
